# Система учета актеров (ActorsSystem) - Этап ПР7

## Назначение
Учебный проект по дисциплине «Технологии разработки приложений на базе фреймворков». 
Полноценное веб-приложение с базой данных для управления актерами и их фильмографией.

## Используемые технологии
* Python 3.11, Django 5.2
* База данных: SQLite (интеграция через стандартный модуль `sqlite3`, без Django ORM)
* Django Template Language (DTL), HTML5, CSS3, Bootstrap 5.3, JavaScript
* Тестирование: Pytest (23 теста)
* Линтинг: Flake8

## Структура проекта и базы данных
* `sql/schema.sql` — SQL-схема базы данных (таблицы `actors`, `movies`, связующая `movie_actors`).
* `sql/queries.sql` — файл с разработанными SQL-запросами (SELECT, WHERE, JOIN, GROUP BY).
* `db/database.py` — модуль подключения к SQLite (с настройкой `sqlite3.Row`).
* `db/import_json.py` — скрипт переноса данных из JSON в базу.
* `data/actors.sqlite` — файл реляционной базы данных.
* `models/` — классы предметной области `Actor` и `Movie` (реализовано ООП, `__str__`, `@classmethod`).

## Функционал и страницы
* `/` — Главная страница.
* `/actors/` — Список актеров (данные из SQLite).
* `/actors/<id>/` — Карточка актера (параметризованный SQL-запрос).
* `/actors/movies/` — Фильмография (использование JOIN-запроса для связи многие-ко-многим).
* `/actors/statistics/` — Статистика (агрегатный запрос GROUP BY с возможностью фильтрации).

## Тестирование и проверка
* Запуск тестов: `pytest -v` (23 теста).
* Проверка кода: `flake8 . --extend-exclude=venv`.

## Запуск проекта
1. Установить зависимости: `pip install -r requirements.txt`
2. Применить миграции Django: `python manage.py migrate`
3. Запустить сервер: `python manage.py runserver`
4. Открыть: `http://127.0.0.1:8000/`
